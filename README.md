# 🏗️ Elite Construction

Модерен и responsive уебсайт за строителна компания, създаден с **HTML, CSS и JavaScript**.

Проектът представя строителна компания **Elite Construction**, нейните проекти и информация за контакт с модерен и професионален дизайн.

---

## ✨ Features

* 🏠 Модерна Hero секция
* 🧭 Навигация с плавно скролиране
* 🏗️ Секция с реализирани проекти
* 🖼️ Responsive проектни карти
* ✨ Hover анимации
* 📱 Responsive дизайн за мобилни устройства
* 📊 Секция „За нас“ със статистики
* 📩 Контактна форма
* 🔔 Интерактивен Modal прозорец за информация за проектите
* 🎨 Модерен черно-бял дизайн с оранжев акцент
* ⚡ Vanilla JavaScript без допълнителни библиотеки

---

## 🛠️ Technologies

Проектът е изграден с:

* **HTML5**
* **CSS3**
* **JavaScript**
* **Unsplash** – изображения за проектите

## 🚀 How to Run

Не са необходими специални инсталации.

### 1. Clone repository

```bash
git clone https://github.com/YOUR-USERNAME/elite-construction.git
```

### 2. Отвори папката

```bash
cd elite-construction
```

### 3. Стартирай проекта

Просто отвори:

```text
index.html
```

в браузър.
